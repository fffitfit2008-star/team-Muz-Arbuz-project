# Отчет по СР5: Разработка интерфейса сервиса «Муз-Арбуз»

## 1. Перечень экранов и их назначение
1. **Экран авторизации/регистрации** — вход в систему, сбор согласия на обработку персональных данных (согласно правовым требованиям).
2. **Главный экран (Лента рекомендаций)** — вывод персональных рекомендаций треков на основе истории прослушиваний.
3. **Экран плеера** — воспроизведение трека, управление звуком, кнопки лайк/дизлайк.
4. **Экран профиля** — настройки аккаунта, история прослушиваний, выход.
5. **Экран правовой информации** — доступ к Политике конфиденциальности и Пользовательскому соглашению.

## 2. Элементы на основных экранах
* **Главный экран:** 
  * Верхняя панель: логотип, строка поиска, иконка профиля.
  * Центральная часть: карточки с обложками треков и названиями.
  * Нижняя панель: мини-плеер с кнопкой Play/Pause.
* **Экран плеера:**
  * Крупная обложка альбома.
  * Название трека и исполнитель.
  * Полоса прокрутки (таймлайн).
  * Кнопки: "Воспроизвести/Пауза", "Следующий трек", "Лайк", "Дизлайк".
* **Экран профиля:**
  * Аватар, имя пользователя.
  * Список настроек (уведомления, качество звука).
  * Ссылки на правовые документы.

## 3. Карта навигации
* Авторизация -> Главный экран.
* Главный экран -> Плеер (при нажатии на трек).
* Главный экран -> Профиль (через верхнюю панель).
* Профиль -> Экран правовой информации.
* Из любого экрана возможен возврат на Главный экран.

## 4. Обоснование решений
Целевая аудитория сервиса — молодые люди (16–35 лет), активно слушающие музыку со смартфонов. 
Интерфейс спроектирован с учетом мобильных устройств: крупные кнопки управления (удобно нажимать большим пальцем), темная тема (снижает нагрузку на глаза), минимум лишнего текста и акцент на обложках. Правовые экраны вынесены в профиль, чтобы не перегружать главный экран, но всегда были доступны по требованию законодательства.

## 5. Вывод
В ходе работы были спроектированы основные экраны интерфейса музыкального сервиса. Определена структура навигации и элементы управления, обеспечивающие удобство использования (UX) для целевой аудитории, а также учтены требования по размещению правовой информации.
