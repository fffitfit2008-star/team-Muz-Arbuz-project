## 4. Описание распределения обязанностей по работе с репозиторием
На основе матрицы RACI из СР1, обязанности в Git распределены следующим образом:
* **Создание и настройка репозитория:** Исполнитель (R) — Архитектор (Потапкин Н.), Ответственный (A) — Руководитель (Романов Р.).
* **Поддержание структуры папок и файлов:** Исполнители (R) — Все участники для своих разделов, Ответственный (A) — Руководитель (Романов Р.).
* **Написание отчетов по практическим работам:** Исполнители (R) — Все участники согласно своим ролям, Ответственный (A) — Руководитель (Романов Р.).
* **Внесение коммитов с осмысленными сообщениями:** Исполнитель (R) — Каждый участник за свои изменения, Ответственный (A) — Руководитель (Романов Р.).
* **Проверка пул-реквестов (Pull Request) и Слияние веток (merge):** Исполнитель (R) и Ответственный (A) — Руководитель (Романов Р.).
